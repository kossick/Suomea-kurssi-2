## Imperfekti positiivinen

Minä persoona vartalo + **i**

### Verbityypi 1

**Huom! K-P-T: vahva -> heikko**

#### o/ö/u/y

+ **V + i -> Vi**

| infinitiivi | preesensin vartalo | imperfektin vartalo |
| :--         | :--                | :--                 |
| sanoa       | sano-              | sanoi-              |
| kysyä       | kysy-              | kysyi-              |
| istua       | istu-              | istui-              |

#### a/ä/e/i

+ **V + i -> i**

| infinitiivi | preesensin vartalo | imperfektin vartalo |
| :--         | :--                | :--                 |
| matkustaa   | matkusta-          | matkusti-           |
| kirjoittaa  | kirjoi**t**a-      | kirjoi**t**i-       |
| lukea       | lue-               | lui-                |

#### Huom! 2 tauva ja ensimmäisessä tauvassa on a

+ jos molemmatissa tauvassa on a, **toinen a + i -> oi**

| infinitiivi | preesensin vartalo | imperfektin vartalo |
| :--         | :--                | :--                 |
| maksaa      | maksa-             | maksoi-             |
| antaa       | a**nn**a-          | a**nn**oi-          |
| alkaa       | a**l**a-           | a**l**oi-           |

#### Huom! Erikoiset tapaukset

Yleensä, jos 

1. verbin vartalolla on t ja kaksi vokaalia tai n, r tai l t:n edessä, esim. lentää, piirtää, tuntea
2. verbin pääte on taa tai tää (tuntea on poikkeus)

+ **ta/tä + i -> si**

| infinitiivi | preesensin vartalo | imperfektin vartalo |
| :--         | :--                | :--                 |
| teitää      | tiedä-             | tiesi-              |
| pyytää      | pyydä-             | pyysi-              |
| lentää      | le**nn**-          | lensi-              |
| ymmärtää    | ymmä**rr**ä-       | ymmärsi-            |
