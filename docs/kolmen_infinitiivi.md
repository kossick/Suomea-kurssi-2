## Kolmen infinitiivi

Kolmen infinitiivin vartalo on monikko kolmen persoona **minus vat/vät**


| infinitiivi | monikko 3. persoona | 3. infinitiivin vartalo |
| :--         | :--                 | :--                     |
| istua       | istuvat             | istu-                   |
| lukea       | lukevat             | luke-                   |
| syödä       | syövät              | syö-                    |
| kunnella    | kuntelevat          | kuntele-                |
| juosto      | juoksevat           | juokse-                 |
| pelata      | pelaavat            | pelaa-                  |
| lämmetä     | lämpenevät          | lämpene-                |


### Kolmen infinitiivi + inessiivi ➡️

**kolmen infinitiivin vartalo + maan/mään**

Esim. menen ravintolaan syö**mään**

| infinitiivi |  3. infinitiivin vartalo | 3. infinitiivi + inessiivi |
| :--         |  :--                     | :--                        |
| istua       |  istu-                   | istumaan                   |
| lukea       |  luke-                   | lukemaan                   |
| syödä       |  syö-                    | syömään                    |
| kunnella    |  kuntele-                | kuntelemaan                |
| juosto      |  juokse-                 | juoksemaan                 |
| pelata      |  pelaa-                  | pelaamaan                  |
| lämmetä     |  lämpene-                | lämpenemään                |


#### Mitkä verbit tarvitsevat tämä?

menna, lähteä, kävellä, ajaa, ...

### Kolmen infinitiivi + elatiivi ⬇️

**kolmen infinitiivin vartalo + massa/mässä**

Esim. olen ravintolassa syö**mässä**

| infinitiivi |  3. infinitiivin vartalo | 3. infinitiivi + elatiivi |
| :--         |  :--                     | :--                       |
| istua       |  istu-                   | istumassa                 |
| lukea       |  luke-                   | lukemassa                 |
| syödä       |  syö-                    | syömässä                  |
| kunnella    |  kuntele-                | kuntelemassa              |
| juosto      |  juokse-                 | juoksemassa               |
| pelata      |  pelaa-                  | pelaamassa                |
| lämmetä     |  lämpene-                | lämpenemässä              |


#### Mitkä verbit tarvitsevat tämä?

olla, istua, seisoa, käydä, ...

**Huom! olla + mennossa/lähdössä/tulossa = mennä/lähteä/tulla juuri nyt**

**kolmen infinitiivin vartalo + masta/mästä**

Esim. palaan ravintolasta syö**mästä**

| :--         |  :--                     | :--                        |

| lukea       |  luke-                   | lukemasta                  |
| syödä       |  syö-                    | syömästä                   |
| kunnella    |  kuntele-                | kuntelemasta               |
| juosto      |  juokse-                 | juoksemasta                |
| pelata      |  pelaa-                  | pelaamasta                 |
| lämmetä     |  lämpene-                | lämpenemästä               |

#### Mitkä verbit tarvitsevat tämä?

tulla, palata, lähteä, ...
