## Passiivin preesens

### Verbityppi 1

+ minä persoona + **taan/tään**
+ Huom! K-P-T-vaihtelu

| infinitivi | minä vartalo | passiivi |
| :--        | :--          | :--      |
| sanoa      | sano-        | sanotaan |
| lukea      | lue-         | luetaan  |
| kysyä      | kysy-        | kysytään |

+ jos vartalo on a tai ä lopussa: **a/ä -> e myös**

| infinitivi | minä vartalo | a/ä -> e  | passiivi     |
| :--        | :--          | :--       | :--          |
| antaa      | anna-        | anne-     | annetaan     |
| kirjoittaa | kirjoita-    | kirjoite- | kirjoitetaan |
| piirtää    | piirrä-      | piirre-   | piirretään   |


### Verbityppi 2-6

+ infinitivi + **an/än**

| infinitivi | passiivi   |
| :--        | :--        |
| juoda      | juodaan    |
| kävellä    | kävellään  |
| haluta     | haluaan    |
| tarvita    | tarvitaan  |
| vanheta    | vanhetaan  |

### Negatiivinen passiivi

+ **ei** + passiivi **minus an/än**


| infinitivi | passiivi   | negatiivinen passiivi |
| :--        | :--        | :--                   |
| tanssia    | tanssitaan | ei tanssita           |
| alkaa      | aletaan    | ei aleta              |
| syödä      | syödään    | ei syödä              |
| pestä      | pestään    | ei pestä              |
| tavata     | tavataan   | ei tavata             |
| valita     | valitaan   | ei valita             |
| lämmetä    | lämmetään  | ei lämmetä            |
